# HireLens

HireLens is an AI-powered talent assessment and recruitment platform.

## Project Structure

This project is organized as a monorepo consisting of:
- `frontend/`: Multi-app React SPA powered by Vite.
- `backend/`: Django project with custom tenant, candidate, assessment, and scoring systems.
- `database/`: Database designs, migrations, and backups.
- `docs/`: Technical and product documentation.
- `scripts/`: Development and build helper scripts.

## Running Locally

Refer to the documentation under `docs/developer/getting_started.md` to set up your environment.
